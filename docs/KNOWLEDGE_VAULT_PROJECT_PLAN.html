01 · Executive Summary

执行摘要

KnowledgeVault 是一个开源的个人知识库收集整理工具箱，旨在将散落在各处的信息碎片（网页、微信文章、AI 对话、笔记）自动转化为结构化的知识资产。本项目基于 Kami 设计系统和 clip-to-kami 内容转换引擎，提供优雅的 PDF 排版输出。

核心 Takeaways

  • 一键收集：浏览器扩展、剪贴板监控、API 接口，多源信息自动归集
  • 智能整理：AI 自动摘要、标签提取、去重检测，零维护成本
  • 强大搜索：Meilisearch 全文索引，10 万条目秒级响应
  • 优雅输出：Kami 排版 PDF，支持批量导出和合集管理
  • 数据自主：本地 SQLite 存储，可选云盘同步（rclone 外挂）

  • 技术架构如何支撑产品愿景？

项目背景

在信息爆炸的时代，我们每天接触大量有价值的内容：技术博客和新闻文章、微信公众号深度内容、AI 工具的对话问答、个人笔记和灵感记录。这些知识碎片散落在各处，缺乏统一的收集、整理、检索机制，导致：

  • 重复收集：同样的内容存了多次
  • 检索困难：想找之前的内容找不到
  • 价值流失：优质内容逐渐遗忘

项目愿景

"你的第二大脑，优雅地归集网络碎片。" — KnowledgeVault 项目宣言

核心价值主张

价值维度 传统方案 KnowledgeVault
收集效率 手动复制粘贴 一键保存 + 剪贴板监控
整理成本 手动分类打标签 AI 自动摘要 + 智能标签
搜索能力 文件名搜索 全文索引 + 多维过滤
输出质量 普通打印 Kami 专业排版 PDF
数据控制 云端 SaaS 本地存储 + 可选同步
02 · Objectives

核心目标

KnowledgeVault 的核心目标是构建一个跨平台、智能化、优雅输出的个人知识库管理系统。

功能目标

模块 功能 优先级
收集器 网页/微信/AI对话/本地文件 P0
处理器 AI摘要/标签/去重 P0
存储 SQLite/全文索引 P0
搜索 全文搜索/过滤/排序 P1
导出 Kami PDF/合集导出 P0
同步 云盘备份 P1

技术目标

  • 跨平台：支持 macOS、Linux、Windows 11 原生运行
  • 双模式：CLI 工具 + Skill 插件（兼容 Claude Code 等平台）
  • 高性能：10 万条目秒级搜索（< 100ms）
  • 可扩展：插件化架构、RESTful API 接口

用户体验目标

  • 零学习成本：Skill 模式下自然语言交互
  • 自动化：剪贴板监控、AI 整理、去重检测全自动化
  • 优雅输出：Kami 排版 PDF，适合打印和归档
  • 数据安全：本地存储、数据自主、可选云盘备份
03 · Product Design

产品设计

KnowledgeVault 面向的是终身学习者、技术开发者、内容创作者和研究人员。

用户画像

用户类型 核心痛点 核心需求
技术开发者 技术文章散落在各处 快速收集、代码搜索、技术归类
内容创作者 灵感和素材管理混乱 标签系统、合集管理、快速检索
研究人员 文献和笔记整理困难 学术引用、PDF 导出、文献归档
终身学习者 AI 对话和课程无法沉淀 知识沉淀、定期回顾、批量导出

核心使用场景

场景 1：网页一键收集

用户浏览技术博客时，点击浏览器扩展 → 自动保存到知识库 → AI 自动生成摘要（3条要点）→ 智能提取标签（#Python #异步编程）→ 去重检测（避免重复保存）。

场景 2：AI 对话归档

用户使用 ChatGPT 对话 → 复制对话内容 → 剪贴板自动监控识别 AI 对话模式 → 提取问答对 → 保存为结构化条目（问题+答案）→ 关联相关主题标签。

场景 3：知识检索

用户搜索 "Python 异步" → 全文索引匹配 → 返回相关条目（按相关度排序）→ 支持过滤（按标签、时间、来源）→ 快速预览 + 一键导出 PDF。

场景 4：定期整理

用户选择最近 30 天条目 → 按主题自动分组 → 创建合集 "Python 学习 2026-05" → 批量导出为 Kami PDF → 归档到云盘备份。

用户交互设计

CLI 模式（核心交互）
# 添加条目
kv add https://example.com/article
kv add --clipboard                  # 从剪贴板
kv add --file ~/notes/idea.md

# 搜索
kv search "Python 异步"
kv search --tag "机器学习" --tag "论文"

# 组织
kv collection create "Python 学习"
kv move 20260512_abc123 "Python 学习"

# 导出
kv export "Python 学习" --pdf
Skill 模式（AI Agent 交互）
用户：把这篇文章保存到知识库：https://example.com/python-async
AI：✓ 已添加到知识库
  • 标题：深入理解 Python 异步编程
  • 标签：#Python #异步编程
  • AI 摘要：本文讲解了 async/await 的原理...
04 · Technical Architecture

技术架构

KnowledgeVault 采用模块化、插件化架构设计，核心依赖 Kami 设计系统和 clip-to-kami 内容转换引擎。

整体架构图

三层架构：收集层（Collector）→ 处理层（Processor）→ 管理层（Vault Manager）。底层复用 clip-to-kami 的内容转换能力，上层提供统一的 CLI 和 Skill 接口。

技术栈选型

层级 技术选型 选型理由
后端框架 Python 3.10+ 复用 clip-to-kami、生态丰富
CLI 框架 Click / Typer 优雅的命令行界面
数据库 SQLite 零配置、本地存储、跨平台
搜索引擎 Meilisearch 轻量级、高性能全文索引
PDF 生成 WeasyPrint Kami 排版兼容
AI 能力 OpenAI API / GPT-4o-mini 性价比高、摘要质量好
浏览器自动化 Playwright + Edge 反爬强、跨平台

数据流设计

输入源 → 标准化 Item → 三层存储（SQLite 元数据 + Meilisearch 索引 + Kami PDF 归档）

目录结构设计

~/KnowledgeVault/
├── config/                   # 配置文件
├── data/                     # 数据存储
│   ├── vault.db             # SQLite
│   └── index/               # Meilisearch
├── items/                    # 知识条目
│   ├── 2026-05/
│   ├── inbox/               # 待整理
│   └── archive/             # 已归档
├── pdf/                      # Kami PDF 归档
└── sync/                     # 云盘同步

数据模型设计

核心数据表：items（知识条目）、collections（知识合集）、tags（标签）、item_tags（关联表）。支持嵌套合集、自动去重、全文索引。

05 · Roadmap

功能规划

开发分为 5 个 Phase，每个 Phase 4-6 周，总计约 18-22 周完成 1.0 正式版。

Phase 1: 核心功能（MVP）- 4-6 周

  • 集成 clip-to-kami 子模块
  • 实现 SQLite 数据存储层
  • 构建 Click CLI 框架
  • 支持从 URL、本地文件添加条目
  • 基础搜索（SQL LIKE）
  • Skill 模式适配

里程碑：能在本地 CLI 环境收集、搜索、查看内容

Phase 2: 智能增强 - 3-4 周

  • AI 摘要生成（OpenAI API）
  • 剪贴板监控（捕获 AI 对话）
  • 自动标签提取（NLP / AI）
  • 去重检测（相似度算法）
  • 合集管理（创建、编辑、删除）
  • 状态管理（inbox → archived → starred）

里程碑：能自动整理、归纳内容

Phase 3: 搜索与导出 - 2-3 周

  • Meilisearch 全文索引集成
  • 高级搜索（多维度过滤）
  • 搜索结果排序（相关度/时间/字数）
  • 批量导出 PDF（合集 → 单份 PDF）
  • 自定义模板（可选）
  • 导出格式扩展（Markdown、JSON、OPML）

里程碑：强大的搜索和导出能力

Phase 4: 生态扩展 - 3-4 周

  • 浏览器扩展（Chrome/Firefox 插件）
  • 云盘同步（基于 rclone）
  • Web UI（MVP，可选）
  • 数据导入/导出（OPML、JSON）
  • RESTful API 接口
  • 插件系统（自定义收集器/处理器）

里程碑：完整的产品体验

Phase 5: Windows 原生支持 - 2-3 周

  • GTK 运行时安装（MSYS2 自动化）
  • 路径适配（Windows 路径处理）
  • doctor.py 环境检测扩展
  • PowerShell 安装脚本（install.ps1）
  • Edge 集成（系统 Edge 替代 Chromium）
  • 功能测试与文档

里程碑：Windows 11 原生运行
