01 · Executive Summary

执行摘要

KnowIt 是一个开源的个人知识库收集整理工具箱，专注于主动收集和智能合并。本项目基于 Kami 设计系统和 clip-to-kami 内容转换引擎，帮助用户将分散的信息转化为结构化的知识库。

核心定位调整

聚焦核心价值，去除复杂度

• 收集方式：改为用户主动发起（CLI 命令、API），不再监控剪贴板或浏览器扩展
• 智能处理：聚焦重复/相似内容的智能合并，而非简单去重
• 云盘同步：延后到 V2.0，V1.0 专注本地存储和导出

核心 Takeaways

  • 简单收集：用户通过 CLI 命令主动添加内容，可控性强
  • 智能合并：自动识别并合并重复、相似内容，减少冗余
  • 强大搜索：Meilisearch 全文索引，毫秒级响应
  • 优雅输出：Kami 排版 PDF，支持批量导出
  • 本地优先：数据存储在本地，V1.0 不依赖云服务

项目背景

在信息爆炸的时代，我们每天接触大量有价值的内容。但这些信息散落在各处，缺乏统一的整理机制。现有工具要么过于复杂（Notion 全功能套件），要么功能单一（稍后读工具）。

"KnowIt 不做'全能笔记'，而是做好'收集→合并→导出'这一件事。" — KnowIt 设计哲学

核心价值主张

维度 传统方案 KnowIt
收集方式 手动复制粘贴 CLI 命令主动收集（用户可控）
内容处理 简单去重 智能合并重复/相似内容
搜索能力 文件名搜索 全文索引 + 相似度推荐
输出质量 普通打印 Kami 专业排版 PDF
数据存储 云端 SaaS 本地 SQLite（V1.0）
02 · Objectives

核心目标

KnowIt 的核心目标是构建一个简单、智能、优雅的个人知识库管理工具。

功能目标（修订）

模块 功能 优先级
主动收集 CLI 命令/API 接口 P0
智能合并 重复检测/相似内容合并 P0
存储 SQLite/全文索引 P0

设计原则

  • 简单胜于复杂：不监控剪贴板，不做浏览器扩展，用户主动控制
  • 合并胜于去重：不只是删除重复，而是智能合并相似内容
  • 本地胜于云端：V1.0 专注本地存储，不依赖云服务
  • 质量胜于数量：Kami 排版，优雅输出，可打印归档
03 · Product

产品设计

KnowIt 面向的是有整理习惯的知识工作者：开发者、研究人员、内容创作者。

核心场景（修订）

场景 1：主动收集

用户阅读到有价值的内容 → 打开终端 → 执行 kv add https://example.com/article → 自动抓取并保存 → 智能检测是否有重复/相似内容 → 提示合并或新增。

场景 2：智能合并

用户收集了多篇"Python 异步编程"的文章 → KnowIt 自动识别这些内容的相似性 → 提示"发现 3 篇相似文章" → 用户选择合并 → 生成合并后的条目（保留所有要点）。

场景 3：相似推荐

用户搜索"Python 装饰器" → 显示精确匹配的条目 → 同时在侧边栏推荐"相似内容"（基于内容相似度）→ 用户发现遗漏的知识点 → 一键添加到合集。

场景 4：优雅导出

用户完成一个学习主题（如"Python 高级特性"）→ 选择相关条目创建合集 → 执行 kv export "Python 高级特性" --pdf → 生成 Kami 排版的 PDF → 打印归档。

用户交互设计（修订）

CLI 模式：简洁、可控

# 主动收集
kv add https://example.com/article
kv add --file ~/notes/idea.md
kv add --content "直接输入内容..."

# 智能合并
kv merge --similar "Python 异步"    # 合并相似内容
kv merge --duplicate               # 合并完全重复

# 搜索与推荐
kv search "Python 装饰器"
kv recommend --item 20260512_abc123  # 推荐相似内容

# 导出
kv export "Python 学习" --pdf
04 · Features

核心功能

KnowIt 的核心功能围绕主动收集、智能合并、相似推荐展开。

功能一：主动收集

  • URL 收集：kv add <url> 自动抓取网页/微信文章
  • 文件收集：kv add --file <path> 支持 Markdown、txt、HTML
  • 内容收集：kv add --content 直接输入或粘贴内容
  • API 收集：RESTful API 支持第三方工具集成

功能二：智能合并

  • 重复检测：基于 URL、标题、内容指纹检测完全重复
  • 相似度计算：使用 SimHash 或 Embedding 计算内容相似度
  • 智能合并：自动合并相似内容，保留所有要点
  • 合并预览：用户确认合并结果，避免误操作

功能三：相似推荐

  • 基于搜索：搜索时推荐相似内容
  • 基于条目：查看某条目时推荐相关内容
  • 相似度阈值：用户可调整推荐敏感度

功能四：强大搜索

  • 全文搜索：Meilisearch 驱动，毫秒级响应
  • 过滤条件：按标签、时间、来源过滤
  • 排序方式：相关度、时间、字数

功能五：优雅导出

  • 单个导出：单条目导出为 Kami PDF
  • 合集导出：多个条目合并为一份 PDF
  • 黑白版本：生成适合黑白打印的纯白版本
05 · Architecture

技术架构

KnowIt 采用模块化架构，核心依赖 Kami 和 clip-to-kami。

技术栈选型

层级 技术选型 理由
后端框架 Python 3.10+ 复用 clip-to-kami
CLI 框架 Click / Typer 优雅的命令行界面
数据库 SQLite 零配置、本地存储
搜索引擎 Meilisearch 全文索引 + 相似度搜索
PDF 引擎 WeasyPrint Kami 排版兼容
相似度计算 SimHash / Sentence-Transformers 高效去重和相似推荐

数据模型（修订）

核心数据表：items（知识条目）、collections（合集）、tags（标签）、item_similarities（相似度缓存，新增）。

智能合并算法

合并流程

1. 检测相似：计算新内容与现有条目的相似度
2. 提示用户：显示相似内容列表，由用户确认
3. 智能合并：提取各篇内容的要点，去重，生成合并内容
4. 保留历史：原始内容不删除，标记为"已合并"
06 · Roadmap

功能规划

开发分为 4 个 Phase，总计约 14-18 周完成 1.0 正式版。

Phase 1: 核心收集（MVP）- 4-6 周

  • 集成 clip-to-kami（网页/微信/EPUB）
  • 实现 SQLite 数据存储
  • 构建 Click CLI 框架
  • 支持 URL、文件、内容三种收集方式
  • 基础搜索（SQL LIKE）

里程碑：能通过 CLI 收集和搜索内容

Phase 2: 智能合并 - 3-4 周

  • 重复检测（URL、标题、内容指纹）
  • 相似度计算（SimHash）
  • 智能合并算法（要点提取 + 去重）
  • 合并预览和确认界面

里程碑：能自动识别并合并重复/相似内容

Phase 3: 搜索与推荐 - 3-4 周

  • Meilisearch 全文索引集成
  • 高级搜索（过滤、排序）
  • 相似内容推荐
  • 批量导出 PDF（合集）

里程碑：强大的搜索和推荐能力

Phase 4: 完善与优化 - 4-5 周

  • 合集管理（创建、编辑、删除）
  • 标签系统（手动 + AI 自动提取）
  • Windows 原生支持
  • 完整文档和测试

里程碑：生产可用的 1.0 版本

V2.0 规划（未来）

  • 云盘同步（基于 rclone）
  • 浏览器扩展（可选）
  • Web UI（可选）
  • 更多 AI 功能（摘要、标签）
